# wheel

三個轉盤網頁，都是純 HTML/CSS/JavaScript，不需要伺服器，用瀏覽器直接開啟即可使用。

## 今天喝什麼

`今天喝什麼.html` — 依照 `飲料店.txt` 的店家名單產生轉盤，按下轉盤中間的 🧋 按鈕開始旋轉，轉盤逐漸減速停下後，指針指到哪一家，今天就喝那一家。

名單已經直接寫死在頁面裡（查有此人、日丈五、mr. whish、迷客夏、雙十八木、先喝道、上宇林、萬波），開啟頁面即可直接轉，不用先輸入名單。也可以在頁面左側編輯名單後按「產生轉盤」套用新內容。

線上網址（免登入、免安裝，任何人都能直接使用）：
https://claude.ai/code/artifact/471b9833-5dcf-4cb9-8464-cf2572b0ec4a

## 天選之人

`index.html` — 依照 `名單.txt` 的人名產生轉盤，用法與「今天喝什麼」相同，按下中間按鈕即可抽出天選之人，並保留每次抽選的歷史紀錄。

線上網址（免登入、免安裝，任何人都能直接使用）：
https://claude.ai/code/artifact/1e5d7841-caef-476d-a632-1364c776c335

## 晚餐吃什麼

`晚餐吃什麼.html` — 依照 `晚餐.txt` 的選項產生轉盤，按下轉盤中間的 🍱 按鈕開始旋轉，轉盤逐漸減速停下後，指針指到哪一格，今晚就吃那一個。

選項已經直接寫死在頁面裡（滷味、大拇哥鍋燒、芳津素食、八方雲集、三媽臭臭鍋、越南料理、健康餐盒、日式料理、鏘鏘鏘、佑丞、清華鴨肉麵、烤肉配泡麵、土魠魚羹），開啟頁面即可直接轉，不用先輸入名單。也可以在頁面左側編輯選項後按「產生轉盤」套用新內容。

線上網址（免登入、免安裝，任何人都能直接使用）：
https://claude.ai/code/artifact/9d503694-246b-4d82-8e8e-aa2ed8f3b9d9
